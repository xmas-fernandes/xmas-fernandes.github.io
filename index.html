Turn an old Android phone into a useful home server for files, media, photos, downloads, smart home control, and more — without root.

🚀 Getting Started

homedroid is designed for people who want a practical home server without buying extra hardware or learning complicated developer tools. If you have an old Android phone and a Windows computer, you already have the main pieces. The phone becomes the server, and your Windows computer becomes the easy control point.

You do not need programming knowledge. You do not need to root your phone. You use a normal web browser on Windows to open the download page, and you use the homedroid dashboard to manage your services. The dashboard is made to be clear, friendly, and easy to scan.

The first step is simple: open the official download page. From there, you can get the application and follow the on-screen guidance to connect your Android phone and begin using your new home server.

✨ What homedroid Does

homedroid turns an old Android phone into a small home server that can run popular self-hosted tools. Instead of leaving an unused phone in a drawer, you can give it a useful second life. It can store files, serve media, back up photos, download items, and connect to your smart home.

The project focuses on convenience. It brings SSH, web hosting, Jellyfin with hardware transcoding, Immich, qBittorrent, Home Assistant, and a web dashboard together in one place. It also supports remote access tools such as Cloudflare Tunnel and Tailscale, so you can reach your services when you are away from home.

Everything is managed from a web dashboard. That means you can open a browser on Windows, visit your dashboard, and check what is running without typing commands or editing configuration files.

🧰 What You Can Run

  • Jellyfin: Organize and stream your personal movies, shows, music, and home videos. Hardware transcoding helps the phone handle video conversion more smoothly.
  • Immich: Keep your photos and videos backed up in a private photo library that you control.
  • qBittorrent: Manage downloads from a friendly web interface.
  • Home Assistant: Bring smart home devices together and control them from one dashboard.
  • Web hosting: Host simple pages and small web apps directly from the phone.
  • SSH: Use secure remote access for advanced tasks when you need it.
  • llama.cpp: Run lightweight local AI models for small experiments and private testing.
  • Remote access: Use Cloudflare Tunnel or Tailscale to reach your services safely when you are not on your home network.

🖥️ Set Up After Download

When homedroid opens, take your time and read each screen. The setup is written for a normal computer user, not a developer. You will connect your Android phone, confirm that it is reachable, and choose which services you want to use.

Keep the phone plugged into a charger during setup and during everyday use. A home server is meant to stay on, and a charger helps it run reliably. Connect both the Windows computer and the Android phone to the same home network while you get started. This makes the first connection easier to complete.

After the connection is complete, homedroid opens a web dashboard. Bookmark that dashboard in your Windows browser so you can return to it quickly. From the dashboard, you can see which services are available and open the one you want to use.

📊 Using Your Dashboard

The dashboard is the main control area. It gives you a simple view of your homedroid server and the tools you have chosen. Use it to open Jellyfin, browse your Immich photo library, manage qBittorrent downloads, or reach Home Assistant.

If you want to access your server from outside your home, the dashboard also helps you work with remote access options such as Cloudflare Tunnel and Tailscale. These tools are optional. You can start by using homedroid only inside your home network, then add remote access when you feel ready.

The dashboard is meant to remove confusion. You do not need to remember separate addresses for every service. Open the dashboard, choose the service, and continue from there.

💡 Everyday Tips

Use a reliable charger and keep the phone in a cool, well-ventilated spot. Avoid placing it under pillows, blankets, or other items that trap heat. A stable shelf or desk is a good home for a small server.

Give your phone a clear name in the dashboard so you can recognize it later. Keep your Windows browser updated, and save the dashboard link in your bookmarks bar. If you use photo backup or media streaming, start with a small amount of content first and confirm that everything works the way you expect.

When you are not using a service, you can leave it off to keep things simple. homedroid is flexible: begin with one tool, such as Immich or Jellyfin, and add more later when you are comfortable.

🛠️ Help and Troubleshooting

If the Windows computer cannot find your phone, confirm that both devices are connected to the same home network. Check that the phone is awake, charged, and showing the homedroid setup screen. A simple restart of the application can also clear a temporary connection problem.

If a service does not open, return to the dashboard and check whether it is switched on. Some services take a short time to start after you enable them. Wait a moment, then try again from the dashboard instead of using an old browser tab.

For download questions, always return to the official releases page linked on this page. That is where homedroid is published, and it is the safest place to find the current version. Keep the page bookmarked so you can check for updates when needed.
